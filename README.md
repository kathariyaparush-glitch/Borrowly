## ✨ About The Project

College life is full of temporary needs—a scientific calculator for a single midterm, a tripod for a film fest project, a lab coat for chemistry experiments, or a trekking backpack for a weekend getaway. **Borrowly** eliminates unnecessary student spending and hostel clutter by enabling secure peer-to-peer item sharing right on campus.

Designed with a **sophisticated, Framer-style editorial aesthetic**, Borrowly features generous whitespace, smooth micro-interactions, responsive grids, and instant client-side filtering.

---

## 🚀 Key Features

* **🔍 Instant Campus Search & Filters:** Filter items seamlessly by keyword or category (*Academics, Electronics, Hostel Life, Events & Fests*).
* **📱 Responsive Mobile Navigation:** Fully optimized slide-out drawer menu for mobile and tablet users.
* **⚡ Interactive Item Modals:** Detailed views for every listing displaying lender info, rates, descriptions, and borrowing rules.
* **❤️ Campus Wishlist:** Save items directly to your personal wishlist with instant toast feedback.
* **🛡️ Trust & Safety Guidelines:** Built around college ID verification and hostel neighborhood accountability.
